# Honey's Chewz — Website UMKM

Website company profile untuk project Digitalisasi UMKM (UTS), dibuat dengan HTML, CSS, dan JavaScript murni.

## Cara menjalankan
1. Ekstrak folder project.
2. Buka `index.html` di browser, atau gunakan extension Live Server di VS Code.
3. Edit konten dan harga pada `index.html`.
4. Edit tampilan pada `style.css`.
5. Edit interaksi pada `script.js`.

## Struktur
- `index.html` — struktur halaman
- `style.css` — desain dan responsive layout
- `script.js` — mobile navigation dan filter produk
- `assets/` — logo dan foto produk
- `BUSINESS-WEBSITE-BRIEF.md` — brief bisnis dan strategi digital

## Deployment (GitHub + Vercel)
1. Buat repository GitHub baru, misalnya `honeys-chewz`.
2. Upload seluruh isi folder project (bukan folder zip).
3. Buka Vercel, login dengan GitHub, pilih **Add New → Project**.
4. Import repository `honeys-chewz`, biarkan framework preset **Other** dan root directory `/`.
5. Klik **Deploy**. Setelah selesai, salin URL website.
6. Update URL Shopee setelah toko benar-benar dibuat.

## Catatan
Harga, lokasi, jam operasional, dan beberapa produk merupakan konsep/simulasi tugas. Verifikasi dan sesuaikan sebelum website dipakai sebagai bisnis sungguhan.
